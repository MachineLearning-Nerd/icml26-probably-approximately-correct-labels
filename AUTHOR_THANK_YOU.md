# Thank you to the authors

Thank you to Emmanuel J. Candès, Andrew Ilyas, and Tijana Zrnic for developing a rigorous framework for combining model predictions with expert labels while tracking an explicit error budget. The paper's thresholding and routing formulation makes the core mechanism approachable to audit on a small finite example, and the public `pac-labels` implementation gives future reproduction work a useful starting point.

This repository labels its current result as partial so future work can extend the audit without overstating what has been checked.
